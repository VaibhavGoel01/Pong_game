# Pong Game

A browser-based Pong game made using HTML, CSS, and JavaScript. Features include:

- **Single Player**: Play against a basic computer AI.
- **Game Modes**: Choose between a 5, 7, or 11 point game.
- **Winner Display**: Shows the winner once the game ends. Option to start a new game.
- **Controls**: Player paddle (left) is controlled by the mouse.

## Features

- **Game Mode Selection**: Pick your preferred match length before starting.
- **Score Display**: Live score for both the player and AI.
- **Restart Option**: After a game ends, press "Start New Game" to select a new mode and play again.
- **Responsive Controls**: Move your paddle up and down by moving your mouse over the canvas.
- **AI Opponent**: The right paddle is controlled automatically by a simple algorithm.

## How to Play

1. **Open `index.html` in your browser.**
2. **Choose a game mode** (5, 7, or 11 point game) from the menu.
3. **Control the left paddle** using your mouse.
4. **Score points** by making the ball pass the AI paddle.
5. **The first to reach the selected score wins!**
6. **Start a new game** using the "Start New Game" button when the match ends.

## Files

- `index.html` — Main HTML structure and game layout.
- `styles.css` — Visual styling and layout.
- `game.js` — Game logic, controls, and interaction.
